# Add your own logo

Put your own image in the same folder as `index.html`.

- Preferred filename: `site-logo.png`
- Alternative filename: `site-logo.jpg`
- Use a square image with a transparent or dark background if possible.
- Keep the file extension consistent with the actual image format.

The header now reserves a larger logo area and the GROUPCHAT heading is smaller so they read as one centered brand lockup. No logo artwork is generated by the site.
